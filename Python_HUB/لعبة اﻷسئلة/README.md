## وصف المشروع (باللغة العربية)
هذا المشروع عبارة عن لعبة مسابقات واختبارات تفاعلية متطورة موجهة لمبرمجي لغة بايثون، تم تصميمها خصيصاً لبيئة نظام تشغيل **لينكس منت (Linux Mint)**. تم الانتقال بالمشروع من مجرد برنامج نصي بسيط إلى تطبيق سطح مكتب رسومي متكامل بواجهات حديثة ونظام إدارة مستخدمين آمن ومتوافق تماماً مع حماية النظام وحزم البيانات وعزل الحزم عن نظام التشغيل.

###  الميزات الرئيسية:
* **واجهة رسومية متطورة (PyQt5 GUI):** تصميم واجهات تفاعلية جذابة وسلسة للمستخدمين مع أزرار ومؤقت بصري رقمي يتناقص.
* **دعم مثالي للغة العربية للينكس:** معالجة النصوص البرمجية لضمان ظهور الكلمات العربية بحروف متصلة وصحيحة 100% بدون مشاكل انعكاس الحروف.
* **قاعدة بيانات مستقلة (SQLite3):** نظام تسجيل دخول وإنشاء حسابات للاعبين متعددين، مع حفظ "أعلى سكور" (High Score) لكل لاعب بشكل دائم.
* **تشفير كلمات المرور:** تأمين بيانات المستخدمين داخل قاعدة البيانات عبر استخدام خوارزمية التشفير الحماية والسرية (SHA-256).
* **بيئة معزولة ونظيفة:** يعتمد المشروع على هيكلية احترافية تعزل الحزم والمكتبات عن ملفات نظام التشغيل الأساسية لتفادي أي تداخل.

##  الأوامر التنفيذية النهائية بالتسلسل (تُكتب في الـ Terminal)

### المرحلة 1: بناء وتفعيل البيئة الوهمية وتثبيت المكتبات

```bash
# 1. إنشاء مجلد البيئة الوهمية venv تلقائياً داخل مجلدك
python3 -m venv venv

# 2. تفعيل البيئة الوهمية (ستلاحظ ظهور كلمة (venv) في أول السطر)
source venv/bin/activate

# 3. تثبيت المكتبات البرمجية داخل البيئة المعزولة بأمان وبدون أي خطأ حماية
pip install PyQt5 arabic-reshaper python-bidi pyinstaller

# 4. تدوين وتوليد ملف الحزم requirements.txt تلقائياً في مجلدك
pip freeze > requirements.txt
```

### المرحلة 2: تشغيل اللعبة وتجربتها

```bash
# أمر تشغيل اللعبة الرسومية فوراً للتأكد من أن كل شيء يعمل
python3 main.py
```

### المرحلة 3: تحويل اللعبة إلى تطبيق مستقل بالأيقونة (نسخة اللينكس)

```bash
# 1. أمر تحويل الكود وحقن الأيقونة logo.png داخل التطبيق بشكل دائم
pyinstaller --noconsole --onefile --add-data "logo.png:." --icon=logo.png main.py

# 2. الدخول إلى مجلد التوزيع dist الناتج عن التحويل
cd dist

# 3. إعطاء صلاحية التشغيل للملف في اللينكس لكي يفتح بضغطة زر بالفأرة
chmod +x main
```

##  Project Description (English)
An advanced, interactive desktop quiz application tailor-made for Python developers, fully optimized for the **Linux Mint** environment. Moving away from standard command-line interfaces, this application boasts a production-ready graphical interface, secure multi-user authentication, and system-isolated dependency management.

### Key Features:
* **Modern GUI (PyQt5):** Designed with clean, modular, and dynamic desktop interfaces featuring a built-in countdown timer.
* **Flawless Arabic Support for Linux:** Integrated advanced reshaping engines tailored for Linux environments to ensure native Arabic text layout rendering without reversals.
* **Secure Database Integration (SQLite3):** Multi-player login/registration infrastructure that updates and permanently persists individual high scores.
* **Password Hashing Protection:** Implemented robust cryptography utilizing SHA-256 hashing to secure user records inside the database.
* **Isolated Environment:** Utilizes a highly structured architecture that isolates packages and dependencies from the host OS files to avoid conflicts.

##  Final Execution Commands in Sequence (To be run in Terminal)

### Phase 1: Creating, Activating the Virtual Environment & Installing Libraries

```bash
# 1. Create the virtual environment folder (venv) automatically inside your directory
python3 -m venv venv

# 2. Activate the virtual environment (you will notice the word (venv) appearing at the start of the line)
source venv/bin/activate

# 3. Install the required python packages safely inside the isolated environment without any OS blockages
pip install PyQt5 arabic-reshaper python-bidi pyinstaller

# 4. Generate the dependencies file (requirements.txt) automatically inside your directory
pip freeze > requirements.txt
```

### Phase 2: Running & Testing the Game

```bash
# Execute the graphical application immediately to verify that everything works flawlessly
python3 main.py
```

### Phase 3: Freezing the Game into a Standalone Desktop Application with Icon (Linux Version)

```bash
# 1. Build the application and inject the icon file (logo.png) permanently into the executable binary
pyinstaller --noconsole --onefile --add-data "logo.png:." --icon=logo.png main.py

# 2. Navigate into the output distribution directory (dist) generated by the compiler
cd dist

# 3. Grant mandatory execution permissions to the executable binary in Linux to enable double-click launching
chmod +x main
```
