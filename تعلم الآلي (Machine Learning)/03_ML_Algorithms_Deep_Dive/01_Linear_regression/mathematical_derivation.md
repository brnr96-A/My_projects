# الخوارزمية 1: الانحدار الخطي البسيط والمتعدد 
* (Linear Regression)
# الهدف: التنبؤ بقيمة مستمرة (مثل سعر سهم أو درجة حرارة) 
* بناءً على ميزة واحدة أو ميزات متعددة.
# الشرح الرياضي:تعتمد الخوارزمية على افتراض وجود علاقة خطية بين 
* المدخلات والمخرجات بالمعادلة:
 * Y(hat) = w1x1 + w2x2 + .... + wnxn = wX + b
*  حيث (W) هو متجه الأوزان (Weights) و (b) هو حد الانحياز (Bias).

# دالة الخسارة (Loss Function): متوسط مربعات الخطأ (MSE):
* \(J(W,b)=\frac{1}{2n}\sum _{i=1}^{n}(y_{i}-\^{y}_{i})^{2}\)
# التحديث عبر الانحدار التدريجي (Gradient Descent):
* \(W=W-\alpha \frac{\partial J}{\partial W},\quad b=b-\alpha \frac{\partial J}{\partial b}\)
