### 📂 (04_LassoRegression)
* **انحدار لاسو (Lasso L1):** تصفير الأوزان غير الحيوية رياضياً كطريقة اختيار للميزات تلقائياً.
* الهدف: منع الإفراط في الملاءمة (Overfitting) 
# مع ميزة إضافية
# وهي اختيار الميزات تلقائيًا 
* (Feature Selection) عن طريق تصفير الأوزان غير المهمة تمامًا.

# الشرح الرياضي:

# يضيف انحدار Lasso حدًا تنظيميًا يُسمى L1 Penalty
# وهو عبارة عن مجموع القيم المطلقة للأوزان مضروبًا في المعامل 
## \(\lambda \) (المعروف بـ alpha في Scikit-Learn):

* \(J_{Lasso}(W,b)=\frac{1}{2n}\sum _{i=1}^{n}(y_{i}-\^{y}_{i})^{2}+\lambda \sum _{j=1}^{m}|{}w_{j}|{}\)


# طبيعة الشكل الرياضي لحد العقوبة المشتق من القيمة المطلقة يمتلك زوايا حادة، مما يتيح للحل الأمثل (Optimal Solution) أن يتقاطع مع المحاور تمامًا، وبالتالي تصفير معاملات الميزات غير الحيوية وتحويل المصفوفة إلى مصفوفة خفيفة (Sparse Matrix).
