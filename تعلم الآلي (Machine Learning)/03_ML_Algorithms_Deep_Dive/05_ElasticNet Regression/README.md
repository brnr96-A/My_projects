## الخوارزمية 5: انحدار الشبكة المرنة (ElasticNet Regression)
# الهدف: الدمج الهجين بين عقوبتي
 ### Ridge و Lasso معًا للتعامل مع البيانات التي تحتوي على ميزات متعددة شديدة الارتباط (Multicollinearity).
# **الشرح الرياضي:**
# يجمع نموذج ElasticNet 
### بين حدي التنظيم L1 و L2 في دالة خسارة واحدة،
## ويتحكم في نسبة المزج بينهما عبر معامل يسمى l1_ratio
* يرمز له بـ rho :
## **J_{ElasticNet}(W,b)=\frac{1}{2n}\sum _{i=1}^{n}(y_{i}-\^{y}_{i})^{2}+\lambda \cdot \rho \sum _{j=1}^{m}|{}w_{j}|{}+\frac{\lambda \cdot (1-\rho )}{2}\sum _{j=1}^{m}w_{j}^{2}**

# حيث إذا كانت rho = 1 
 * نتحول إلى Lasso 
#  وإذا كانت rho = 0 
* نتحول إلى Ridge

#  يفيد هذا الدمج عندما تكون الميزات مرتبطة ببعضها في مجموعات
## حيث يقوم Lasso باختيار ميزة عشوائية ويصفر الباقي
