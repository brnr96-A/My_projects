# 📊 الفلسفة الهندسية خلف Matplotlib و Seaborn

عند بناء النماذج، لا يمكننا الثقة بالأرقام الصرفة دائماً. نحتاج لرؤية هندسة البيانات بصرياً.

### 1. مكتبة Matplotlib (المحرك الأساسي منخفض المستوى - Low-level)
*   تعتبر الجد الأكبر لكل مكتبات الرسم البياني في بايثون.
*   تمنحك تحكماً مطلقاً ومفصلاً في كل نقطة، بكسل، خط، نص، ومحور في الرسم.
*   تحتاج لكتابة سطور كود أكثر، لكنها الأساس الذي تُبنى عليه المكتبات الأخرى.

### 2. مكتبة Seaborn (المحرك عالي المستوى - High-level الإحصائي)
*   مبنية بالكامل فوق Matplotlib وتتكامل بشكل مثالي مع Pandas DataFrames.
*   مصممة خصيصاً للرسومات الإحصائية المعقدة (Statistical Plotting) بسطر كود واحد أو سطرين.
*   تأتي بقوالب ألوان احترافية وتتحمل خلف الكواليس عمليات التجميع والحساب الإحصائي تلقائياً.

### 📊 [3. استكشاف البيانات وتحليلها بصرياً (EDA)]
* دراسة وتوزيع الميزات الفردية واكتشاف القيم الشاذة المتطرفة (`histplot`, `boxplot`).
* تحليل العلاقات الثنائية وفحص خطوط الاتجاه والانحدار الخطي (`scatterplot`, `regplot`).
* مقارنة الفئات المتعددة وتحليل الكثافة الاحتمالية للتصنيفات (`barplot`, `violinplot`).
* **تطبيق عملي للـ ML:** بناء خريطة الارتباط الحرارية (`Heatmap`) لترشيح وحذف الميزات المتكررة (Multicollinearity).
