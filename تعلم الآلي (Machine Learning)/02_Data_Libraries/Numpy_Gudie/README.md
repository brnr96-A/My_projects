# 🧮 مسار إتقان مكتبة NumPy من الصفر | NumPy Lib

###  إعداد البيئة البرمجية وتثبيت المكتبة
```bash
# إنشاء بيئة افتراضية (ينصح به لعزل المشروع)
python -m ML_env venv

# تفعيل البيئة الافتراضية

# على نظام Linux:
source ML_env/bin/activate

# تثبيت مكتبة NumPy
pip install numpy
```

## 📚 (جدول المحتويات)

### 📌 الجزء 1: إنشاء المصفوفات الأساسية (`01_arrays_basic`)
*   `01_creation.py`: كيفية إنشاء المصفوفات من القوائم أو باستخدام دوال جاهزة مثل `zeros` و `ones`.
*   `02_attributes.py`: معرفة أبعاد مصفوفة البيانات (`ndim`)، شكلها الهيكلي (`shape`)، ونوع بياناتها (`dtype`).
