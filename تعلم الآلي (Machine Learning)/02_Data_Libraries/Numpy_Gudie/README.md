# 🧮 مسار إتقان مكتبة NumPy من الصفر | NumPy Lib

###  إعداد البيئة البرمجية وتثبيت المكتبة
```bash
# إنشاء بيئة افتراضية (ينصح به لعزل المشروع)
python -m ML_env venv

# تفعيل البيئة الافتراضية

# على نظام Linux:
source ML_env/bin/activate

# تثبيت مكتبة NumPy
pip install numpy
```

## 📚 (جدول المحتويات)

### 📌 الجزء 1: إنشاء المصفوفات الأساسية (`01_arrays_basic`)
*   `01_creation.ipynb`: كيفية إنشاء المصفوفات من القوائم أو باستخدام دوال جاهزة مثل `zeros` و `ones`.
*   `02_attributes.ipynb`: معرفة أبعاد مصفوفة البيانات (`ndim`)، شكلها الهيكلي (`shape`)، ونوع بياناتها (`dtype`).

### 📌 الجزء 2: العمليات الرياضية والإحصائية (`02_math_operations`)
*   `01_arithmetic.ipynb`: العمليات العنصرية الأساسية وعمليات ضرب المصفوفات الحقيقية (Dot Product).
*   `02_statistics.ipynb`: حساب المتوسط، المجموع، والانحراف المعياري العام أو عبر محاور محددة.
*   `03_broadcasting.ipynb`: تطبيق العمليات الرياضية التلقائية بين مصفوفات ذات أبعاد متباينة.
